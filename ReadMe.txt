Video Downloader App

How to use:

1. Install FFmpeg on your PC
  Go to https://ffmpeg.org/download.html
  Download and install it
  Make sure it’s added to your system PATH

2.Download the app
  Go to the Releases section of this GitHub repo
  Download the latest release

3. Run the app
  Open the app it will not show a normal window
  It will go to the system tray (bottom right corner)
  Open the app from the tray(click the system tray icon)
  A menu will show up, select what option you want and paste the link of the video.
  The app will download the video
  First time setup the app will create a config.json file this file saves your output folder it will remember it for next time.

4. Make it run on startup (recommended)
  You can use the automatic file or do it manualy:
  Press Win + R
  Type: shell:startup
  Press Enter
  In the folder add a shortcut of the app
  Right click → New → Shortcut
  Select your app .exe file
  Finish setup

Now the app will start automatically when your PC turns on.
